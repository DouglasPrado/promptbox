# Reference pattern

A strong `DESIGN.md` has two layers.

## Normative system

Compact machine-friendly YAML: semantic colors, typography, radii, spacing, recurring component recipes.

## Application logic

Markdown explains identity, hierarchy, depth, brand color use/avoidance, layout grammar, dominant components, responsive transformations, prohibited drift, extension rules, and uncertainty.

Critical rules may intentionally repeat across tokens, explanation, and guardrails when that redundancy reduces agent drift.

Never mechanically copy example-site values.
