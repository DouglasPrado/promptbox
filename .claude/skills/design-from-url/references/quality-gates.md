# Quality gates

1. **Evidence** — every normative token supportable by observed/strongly derived evidence. Invented precision is critical failure.
2. **Coverage** — primary + representative routes when available.
3. **Visual verification** — browser evidence required when browser tooling exists; degraded mode must be disclosed otherwise.
4. **System extraction** — token scales represent recurrence, not raw CSS dump.
5. **Visual DNA** — hierarchy, depth, color, typography, spacing, shapes, imagery, interactions, signature and forbidden moves documented.
6. **Drift prevention** — Do's/Don'ts concrete and source-specific.
7. **Responsive** — exact breakpoints only when evidenced.
8. **Consistency** — all `{token.references}` resolve and prose agrees with frontmatter.
9. **Independent critique** — no unresolved blocker.
10. **Lint** — official lint zero errors when CLI can run; otherwise state why.
11. **Generative coherence** — a new unseen screen remains recognizably coherent from DESIGN.md alone.
