# Visual DNA schema

Before final tokens, synthesize:

## hierarchyEngine
What consistently creates priority: display scale, surface contrast, whitespace, image scale, color, placement, etc.

## depthEngine
How foreground/background relationships work: tonal ladder, shadows, borders, glass, overlap, none.

## colorStrategy
How much color exists, where it appears, and where it is deliberately withheld.

## typographyCharacter
Family plus weight range, tracking, display/body contrast, capitalization, mono usage, editorial vs UI character.

## spacingCharacter
Compact, generous, rhythmic, grid-tight, asymmetric, dense, section-expansive, or mixed.

## shapeLanguage
Sharp, subtly rounded, soft, pill-heavy, circular, mixed; include meaningful exceptions.

## imageryStrategy
Dominant media and its framing/cropping.

## interactionCharacter
How hover/focus/selected states communicate: color, surface, border, motion, scale, etc.

## signatureMoves
List 3–7 recurring reusable moves that make the product recognizable.

## forbiddenMoves
List 3–7 choices that would materially break fidelity.
